Set up Apple Music Downloader

A few things need to be in place before the first download. This checks itself — fix anything red and it updates automatically.

Sign in to Apple Music
Used once to create a local session token. An active Apple Music subscription is required.
Your password is passed straight to the container for this one sign-in and is never written to disk or committed to git. Only the resulting session token is saved, under rootfs/data/. If your account has two-factor auth, use an app-specific password.
